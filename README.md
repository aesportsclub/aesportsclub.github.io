# AE SPORTS

Dirección pública gratuita: **https://aesportsclub.github.io/**

Este repositorio configura la publicación de la web con la marca AE SPORTS. El
código principal sigue en
[eduardcarrera00-pixel/RCM-Sports](https://github.com/eduardcarrera00-pixel/RCM-Sports),
para mantener un único lugar donde realizar las mejoras de diseño y funcionalidad.

## Publicación y actualizaciones

GitHub Pages publica los archivos actuales de la rama `main` del código principal.
El flujo `Publish AE SPORTS` comprueba los cambios cada cinco minutos; GitHub puede
retrasar las ejecuciones programadas. Si la versión publicada ya está al día, no
vuelve a desplegarla. También se puede ejecutar desde **Actions → Publish AE SPORTS
→ Run workflow**.

El archivo público `source-revision.txt` identifica la revisión publicada.
Si GitHub desactiva las ejecuciones programadas por inactividad prolongada,
se pueden volver a habilitar desde Actions. La última web publicada continúa
disponible mientras tanto.

Se usa el plan gratuito de GitHub para la organización, el repositorio público,
GitHub Pages y los runners públicos de GitHub Actions. No hay un dominio `.com`
contratado ni un servicio de alojamiento de pago.

Las noticias, los picks, los comentarios y las cuentas utilizan la misma
configuración de datos que la página original.
