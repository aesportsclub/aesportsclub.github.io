# AE SPORTS publishing

This repository publishes the free branded address https://aesportsclub.github.io/.

The application source remains in https://github.com/eduardcarrera00-pixel/RCM-Sports.
Make design, functionality, and application fixes in that source repository and
follow its AGENTS.md. Do not create a second independently edited application here.

The publication workflow reads the latest source main branch, preserves its
tracked files, and publishes them through GitHub Pages. It runs on changes here,
manual dispatch, and a five-minute schedule. Unchanged scheduled runs skip
publication. GitHub may delay schedules or disable them after a long period of
repository inactivity; use Actions to re-enable or manually run the workflow.

Keep the repository public and use only free GitHub Pages and public GitHub-hosted
Actions runners. Do not add payment details, paid runners, secrets, access tokens,
or independent database configuration. All application data and authentication
continue to use the original source configuration.
